# Currículum Vitae Web - Kenny Menjivar

Repositorio del proyecto de **Currículum Vitae Web**, desarrollado para la clase de **Desarrollo Web** en la Universidad Tecnológica Centroamericana (**UNITEC**).

---

## 📋 Descripción

Este proyecto consiste en una página web personal que presenta el currículum vitae de **Kenny Menjivar**. Cuenta con un diseño moderno, estructurado en tarjetas, responsivo y con estilos CSS personalizados.

---

## 🚀 Tecnologías Utilizadas

* **HTML5**: Estructuración semántica del contenido (`<header>`, `<main>`, `<section>`).
* **CSS3**: Diseño visual moderno, variables CSS, efectos hover, diseño responsivo y fotografía de perfil enmarcada.
* **Git & GitHub**: Control de versiones y alojamiento del repositorio.

---

## 📁 Estructura del Proyecto

```text
CV-DesarrolloWebKennyMenjivar/
├── images/

│   └── foto-perfil.jpg     # Copia de respaldo

```

---

## 📑 Secciones del Currículum

1. **Encabezado**: Fotografía de perfil profesional enmarcada, nombre completo y título.
2. **Perfil**: Descripción del perfil como estudiante e intereses en desarrollo web.
3. **Educación**: Formación académica en UNITEC.
4. **Experiencia**: Experiencia en proyectos académicos y personales.
5. **Proyectos**: Participación en desarrollo de aplicaciones web.
6. **Habilidades**: Tecnologías dominadas (HTML, CSS, JavaScript).
7. **Contacto**: Correo institucional y teléfono.

## 💻 Visualización del Proyecto

1. Clona o descarga este repositorio:
   ```bash
   git clone https://github.com/Kenny5231/CV-DesarrolloWebKennyMenjivar.git
   ```
2. Abre la carpeta del proyecto en tu editor de código o explorador de archivos.
3. Abre el archivo `MyCD.html` en cualquier navegador web (Chrome, Edge, Firefox).
