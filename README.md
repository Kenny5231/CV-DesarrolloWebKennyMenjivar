# Currículum Vitae Web - Kenny Menjivar

Bienvenido al repositorio del proyecto de **Currículum Vitae Web**, desarrollado para la clase de **Desarrollo Web** en la Universidad Tecnológica Centroamericana (**UNITEC**).

---

## 📋 Descripción

Este proyecto consiste en una página web personal interactiva y moderna que presenta el perfil profesional, formación académica, habilidades, proyectos y datos de contacto de **Kenny Menjivar**, construida utilizando estándares modernos de desarrollo web front-end.

---

## 🚀 Tecnologías Utilizadas

* **HTML5**: Estructuración semántica del contenido (`<header>`, `<main>`, `<section>`, entre otros).
* **CSS3**: Diseño visual personalizado, sistema de diseño con variables CSS, sombras elegantes, tarjetas y diseño responsivo adaptativo para móviles y escritorio.
* **Git & GitHub**: Control de versiones y publicación del repositorio.

---

## 📁 Estructura del Proyecto

```text
CV-DesarrolloWebKennyMenjivar/
├── images/
│   └── foto-perfil.jpg     # Fotografía de perfil profesional
├── MyCD.html               # Documento principal del currículum (HTML5)
├── styles.css              # Hoja de estilos externa vinculada (CSS3)
├── .gitattributes          # Configuración de atributos de Git
└── README.md               # Documentación general del proyecto
```

---

## 🎨 Secciones Incluidas

1. **Encabezado (Header)**: Fotografía de perfil profesional con marco estilizado, nombre completo y título profesional.
2. **Perfil**: Resumen del enfoque e intereses en el área de desarrollo web.
3. **Educación**: Formación académica universitaria en UNITEC.
4. **Experiencia**: Trayectoria y desarrollo de proyectos prácticos.
5. **Proyectos**: Participación en proyectos académicos y personales.
6. **Habilidades**: Competencias técnicas en tecnologías web (HTML, CSS, JavaScript).
7. **Contacto**: Información de comunicación directa (correo institucional y teléfono).

---

## 💻 Cómo Ejecutar el Proyecto

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/Kenny5231/CV-DesarrolloWebKennyMenjivar.git
   ```
2. **Abrir la carpeta del proyecto**:
   ```bash
   cd CV-DesarrolloWebKennyMenjivar
   ```
3. **Visualizar en el navegador**:
   * Haz doble clic en el archivo `MyCD.html` para abrirlo en tu navegador favorito (Chrome, Edge, Firefox, etc.).
   * O utiliza la extensión **Live Server** en tu editor de código para una previsualización en vivo.
